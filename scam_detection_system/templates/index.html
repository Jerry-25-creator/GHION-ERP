Machine Learning-Based Scam Detection System

Paste a text message you are unsure about. A machine learning model trained on labelled examples will estimate whether it looks legitimate or like a potential scam.

Analyze a Message

How scam detection works

1

You submit a message

The text is checked and cleaned (for example converted to lowercase). Links are never opened.

2

Text becomes numbers

TF-IDF converts words into numbers that show how important each word is in the message.

3

The model predicts

A classifier trained on real labelled messages estimates whether the message resembles known scams.

4

You get an explanation

You see the prediction, a confidence estimate and any warning signs found in the text.

Please verify independently

This tool gives an automated assessment, not a guarantee. A legitimate message can be flagged by mistake, and a new type of scam may not be recognised. Before sending money, sharing a PIN or password, or clicking a link, contact the organisation directly using details you already trust.
